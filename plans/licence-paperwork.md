# Licence paperwork: metadata, third-party notices, the wasm port's notice

`plans/licence-paperwork.md`

Follows `plans/monetization-and-licensing.md` ("Compliance gaps" 4, 5 and 6).
Started 2026-10-26 (US Pacific).

## Goal

Make what FarmSlicer distributes carry the notices its licences require:

1. `license` metadata in `Cargo.toml` and `web/package.json`, and a short
   explanation of the AGPL-3.0-or-later / AGPL-3.0-only split (`NOTICE`).
2. A third-party notices file covering what is distributed (Rust crates linked
   into the server, npm packages in the web bundle, the C++ libraries linked
   into the server and the wasm engine), reproducible by a script, committed,
   shipped in the Docker image and in `dist/web`.
3. Fix `wasm/NOTICE.orcaslicer-wasm.md` ("all rights reserved") and the
   README's credit of the wasm port.

Out of scope (other threads or the maintainer): `src/bambu/data/hms.json`,
trademarks, the in-app source link, the OpenSSL 1.1.1 build issue, the ops
repo and servers.

## Decisions already made (don't re-ask)

- Own code AGPL-3.0-or-later; builds with libslic3r AGPL-3.0-only (the
  report's recommendation, open question 1 there). `LICENSE` stays the
  verbatim AGPL text; the explanation is in `NOTICE`.
- The wasm port credit: `JoshTheDerf/orcaslicer-wasm` (Joshua Bemenderfer,
  May-Sep 2026: v2.4.2 port, mt variant, vendored toolchain) is a GitHub fork
  of `allanwrench28/orcaslicer-wasm` (Allan Wrench / WrenchWorks3D, Oct 2025).
  Both have the identical `LICENSE` (AGPL-3.0-or-later, Allan's copyright,
  added upstream 2025-10-27 in `4fedac2`) and the identical stale `NOTICE.md`;
  ours are byte-for-byte copies. Checked through the GitHub API.

## Design (third-party notices)

- `THIRD-PARTY-NOTICES.txt` at the repo root, generated by
  `scripts/third-party-notices.mjs` (Node or Bun, no dependencies):
  - Rust: `cargo metadata --locked --filter-platform x86_64-unknown-linux-gnu`,
    normal dependencies reachable from `farmslicer` (no dev/build deps);
    licence texts from each crate's own LICENSE/COPYING/NOTICE files.
  - npm: the production dependency closure of `web/package.json` in
    `web/node_modules`; licence texts from each package's files. The Vite
    build checks every package actually in the bundle is listed.
  - C++ and data: hand-maintained `scripts/third-party-notices/native.json`
    (component, version, licence, where it ships, upstream) and the licence
    texts in `scripts/third-party-notices/native/`, harvested once from the
    pinned sources by `scripts/third-party-notices/harvest-native.mjs` (run on
    buildhost: it downloads the deps' archives).
- The web build copies it (plus `LICENSE`, `NOTICE`) into `dist/web`, served
  at `/THIRD-PARTY-NOTICES.txt`; the Docker runtime stage copies them to
  `/app`.

## Findings / gotchas

- The Docker deps stage builds `dep_Blosc dep_Boost dep_CGAL dep_CURL
  dep_Cereal dep_Draco dep_Eigen dep_FREETYPE dep_GMP dep_JPEG dep_MPFR
  dep_NLopt dep_OCCT dep_OpenCV dep_OpenEXR dep_OpenSSL dep_OpenVDB dep_PNG
  dep_Qhull dep_TBB dep_libnoise` (buildhost `~/farmslicer-docker-build.log`).
  zlib is Ubuntu 24.04's (`zlib1g-dev`, via `libfontconfig1-dev`); expat is
  OrcaSlicer's `deps_src/expat`.
- The wasm engine uses its own dep versions (`wasm/toolchain/build-deps.sh`):
  Boost 1.84.0, GMP 6.3.0, MPFR 4.2.2, CGAL 5.6.3 (6.1 is installed but not
  used), Eigen 5.0.1, libnoise 1.0, NLopt 2.9.1, Cereal 1.3.2, oneTBB
  2022.3.0 (mt only), and Emscripten 6.0.10's ports of zlib, libpng, libjpeg
  and FreeType.
- This worktree has no OrcaSlicer submodule checkout; the main checkout's is
  at the pinned commit (`8500fcd`, v2.4.2) and was read from there.
- The Bash tool's worktree guard refuses commands that mention a path with
  "git" in it next to a git-like command; use relative paths from the
  worktree.

`auth::remote_gate`, so they are public, which the AGPL wants).

## Known limits

- The npm list is the production dependency tree, so it over-includes a few
  packages the bundle tree-shakes away (`cross-env`, `@types/*` listed as
  runtime dependencies by drei and friends). Harmless for notices.
- The Rust std's own notices are referenced (toolchain's
  `COPYRIGHT-library.html`, 1.5 MB of HTML), not inlined.
- Ubuntu packages in the image (glibc, libstdc++, fontconfig, tini, curl) are
  covered by their `/usr/share/doc/*/copyright` files in the image.
- Native versions are hand-kept: a deps or toolchain bump must update
  `native.json` (CI can't detect that).

## Things not to do

- Don't edit `LICENSE` (verbatim AGPL text).
- Don't touch `src/bambu/data/hms.json`, the OpenSSL build, trademarks or the
  UI source link (other threads).
